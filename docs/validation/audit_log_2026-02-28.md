## 7. Lessons Learned

1. **Validation must run against real data early.** The inflation bug existed since `04_findings_pipeline.py` was written but wasn't caught until the validation suite ran against actual CSVs.

2. **Derived artifacts drift.** Report chapters, figure scripts, and expert review tables all independently encoded inflated numbers. Without a single source of truth enforced by automated checks, drift is inevitable.

3. **Text-based dedup requires normalization.** Whitespace and case differences in question text create silent dedup failures. Any groupby on text fields needs `.str.strip()` at minimum.

4. **Pipeline reruns can silently corrupt.** Without guards on the findings stage, a well-intentioned pipeline rerun would overwrite corrected files with inflated output. Infrastructure must prevent this.

5. **Blast radius audit before fixing.** Fixing the root cause without understanding propagation would have left stale numbers in expert review tables, figures, and report chapters. The read-only audit first saved a round of corrections.
