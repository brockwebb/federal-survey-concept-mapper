## Methodology

### Counting Unit: Unique Question Texts

**Critical distinction:** Pipeline outputs use question-subtopic combination IDs as the unit of analysis. Some questions appear in multiple Census subtopics, generating multiple IDs. For stakeholder reporting, the relevant metric is **unique question texts** — how many distinct questions have harmonization paths.

### Deduplication Logic

When a question appears in multiple subtopics with different feasibility ratings:
- **Take the best (most favorable) feasibility** across all subtopic appearances
- F1 (direct recode) > F2 (statistical adjustment) > F3 (incompatible)
- A question is harmonizable if **any** of its subtopic pairings received F1 or F2

**Example:** If a CPS question paired with ACS in both "Labor Force" (rated F2) and "Employment Status" (rated F3), we count it once as harmonizable with best feasibility F2.

### Pre-Filtered High-Confidence Matches

The barrier coding pipeline pre-filters out pairs where BOTH classification models rated consolidation_potential='yes' (demographic basics like sex, age, citizenship). These never entered barrier coding, so they have no F1/F2/F3 ratings. We count them as harmonizable with implied F1 feasibility (highest confidence).

**Pre-filtered questions included:**
- CPS: 7 unique questions
- FoodAPS: 5 unique questions

**Examples:** Citizenship status, sex/gender, date of birth, education level

### Topic Assignment

Topics come from Report 01 classification (dual-model consensus with arbitration). For questions appearing in multiple subtopics within the same major topic, we use the first topic assignment from the master dataset.

**Major topics:**
- **Demographic:** Age, Sex, Race, Hispanic Origin, Citizenship, Marital Status, etc.
- **Economic:** Employment Status, Earnings, Hours/Week, Labor Force, Occupation, etc.
- **Social:** Disability, Veterans, School Enrollment, SNAP, Health Insurance, etc.
- **Housing:** Tenure, Household Composition, Housing Costs, Migration, etc.

## Notes for Chapter 5

**Key finding:** Demographic questions have the highest harmonization rates (79% CPS, 83% FoodAPS), while Social questions have the lowest (36% CPS, 31% FoodAPS). Economic questions fall in between (57% CPS, 54% FoodAPS).

**Interpretation:** Demographic questions are more standardized across federal surveys (common concepts like age, sex, race), while social program questions exhibit more survey-specific wording and scope variations that create harmonization barriers.
